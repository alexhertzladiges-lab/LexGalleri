# LexGalleri: samme datovisning i tidslinje og gallerier

Kun LexGalleri på https://lexan.dk/lexgalleri/. Gallerier bruger nu tidslinjens datosektioner og miniaturer:6 pr. række på pc og3 på mobil. Sortér efter optagetid eller uploadtid; overskrifterne følger valget. Søgning, daterettelser, billedviser, video og sletningsvalg bevares. Datoernes antal følger de viste filer, og en tømt dato forsvinder.

Offentlig opdatering: installér kun de12 filer fra public/ i den eksisterende verificerede FTPS-rod gennem det eksisterende mål-/TLS-/hashkontrollerede forløb. Brug den grønne kilde og låste artifact. Bevar private programmer, konfiguration, database, medier og routing. Ingen privat upload og ingen SQL er nødvendig. Genindlæs appen efter verificeret overførsel.

Pakken indeholder12 offentlige filer, denne vejledning og SHA256SUMS. Ingen privat PHP, credentials, medlemsdata eller medier. Tests bruger udelukkende syntetiske data og localhost. Installation ændrer ingen rigtige gallerioplysninger som prøve.
